# sinnshr - Personal Portfolio

A modern, interactive personal portfolio website built with React and enhanced with stunning animations and visual effects.

## 🚀 Features

- **Interactive Animations**: Smooth scrolling, text typing effects, and dynamic visual elements
- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI/UX**: Glass morphism effects, gradient backgrounds, and smooth transitions
- **Performance Optimized**: Built with React 19 and optimized for fast loading

## 🛠️ Technologies Used

- **Frontend Framework**: React 19
- **Styling**: Tailwind CSS
- **Animations**: 
  - Framer Motion
  - GSAP (GreenSock)
   - GSAP (GreenSock)
   - [React Bits](https://github.com/DavidHDev/react-bits) — animated components
   - Custom animation components
- **Smooth Scrolling**: Lenis
- **Icons**: React Icons
- **3D Graphics**: OGL
- **Build Tool**: Create React App

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/pikomiko.git
   cd pikomiko
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the application

## 📝 Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm eject` - Ejects from Create React App (one-way operation)
